# Сборник задач по основам Kotlin / Kotlin Basics Practice

### 1. Описание

Этот репозиторий представляет собой сборник решённых задач по основам языка Kotlin. Проект охватывает 22 темы, каждая из которых содержит по 5 практических задач разного уровня сложности.

Задачи сгруппированы по следующим темам:

*   **Основы:** Переменные, типы данных, арифметика, строки и операторы сравнения.
*   **Управление потоком:** Условные операторы (`if/else`, `when`), циклы (`while`, `for`) и диапазоны.
*   **Структуры данных:** Массивы и списки (`List`).
*   **Функциональное программирование:** Функции, лямбда-выражения и extension-функции.
*   **Объектно-Ориентированное Программирование:**
    *   Классы, объекты, конструкторы и `init`-блоки.
    *   Наследование, абстрактные классы и полиморфизм.
    *   Интерфейсы и инкапсуляция.
    *   Сеттеры, геттеры и `companion object`.
*   **Особенности Kotlin:** `Null Safety`, `data class` и `enum`.

### 1. Description

This repository is a collection of solved problems covering the fundamentals of the Kotlin programming language. The project includes 22 topics, each containing 5 practical tasks of varying difficulty.

The tasks are grouped into the following topics:

*   **The basics:** Variables, data types, arithmetic, strings, and comparison operators.
*   **Control flow:** Conditional statements (`if/else`, `when`), loops (`while`, `for`), and ranges.
*   **Data structures:** Arrays and Lists.
*   **Functional programming:** Functions, lambda expressions, and extension functions.
*   **Object-Oriented Programming:**
    *   Classes, objects, constructors, and `init` blocks.
    *   Inheritance, abstract classes, and polymorphism.
    *   Interfaces and encapsulation.
    *   Getters, setters, and `companion object`.
*   **Kotlin-specific features:** Null Safety, `data class`, and `enum`.
